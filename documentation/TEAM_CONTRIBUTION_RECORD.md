# Team contribution record

The repository does not establish who completed each part of SonicSentinel. Its Git
commits currently use one author identity, `Ammar <ammar@nextwave.local>`. That
identity does not prove who wrote, reviewed, tested, or designed each file. The SRS
asks every team member to explain their own modules; this record must be completed
and confirmed by the actual team before submission.

For each contribution, name specific modules, design work, test cases, data work, or
documentation and explain what the person actually did. Link to a commit, pull
request, dated work log, or signed review where available. Do not assign ownership
solely because a filename or old comment says “owner.”

If the competition requires contributions over five working days or commits from
each member, compare that rule with the real Git history and disclose any gap. Do
not backdate commits or invent co-authorship. `documentation/devlog.md` can record
future work as it happens.
