What happens to a file

Every step is recorded against the event it produces.

  1. 1

    Stored as the original

    The file is written under audio_dataset/originals/ hashed by content, so the same bytes never land twice.

  2. 2

    Quality checked

    Silence, clipping, noise floor and length are scored before any model runs, because a bad recording explains a bad prediction.

  3. 3

    Predicted twice, independently

    The Python model and the Teachable Machine model each classify the same signal. Neither is given the other's class or confidence.

  4. 4

    Compared and alerted

    The top classes are compared and the confidence gap is taken as an absolute difference. Severity comes from the alert rules, not from the models.
